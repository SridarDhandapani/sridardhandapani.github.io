# sridar.dev

Personal site of Sridar Dhandapani — CTO at Hoxton AI, ex-McLaren F1.

Live at https://sridar.dev.

## Stack

Hand-written HTML/CSS, vanilla JS for the auto/light/dark theme toggle. No build step. Served from GitHub Pages.

## Local preview

```
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

Push to `main`. GitHub Pages serves the repo root. Custom domain (`sridar.dev`) configured via the `CNAME` file.
